# Contributing To Swap3D

Thanks for taking the time to improve Swap3D.

## Before Opening A Change

- Search existing issues and pull requests.
- Keep bug reports reproducible and remove credentials or private model data.
- Open an issue before large API, format, architecture, or behavior changes.
- Keep changes focused and follow the repository-specific development guide.

## Pull Requests

- Explain the problem and the user-visible result.
- Add or update tests for changed behavior.
- Update documentation when commands, APIs, limits, setup, or deployment
  behavior changes.
- Keep generated files and unrelated formatting changes out of the pull
  request unless they are required.
- Confirm that the repository's documented test and lint commands pass.

By contributing, you agree that your contribution is licensed under the
license of the repository receiving it.
