# Support

## Product And Account Support

For account, billing, API access, or production service questions, email
`support@swap3d.studio`.

Do not include passwords, API keys, session tokens, private model files, or
other credentials in a support request.

## Open Source Support

Use the issue tracker in the affected repository for reproducible bugs and
focused feature requests. Search existing issues before opening a new one and
include the package or CLI version, operating system, command, expected
behavior, and sanitized output.

Use the private process in `SECURITY.md` for suspected vulnerabilities.
