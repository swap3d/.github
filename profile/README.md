<h1 align="center">Swap3D</h1>

<p align="center">3D file conversion for the web, API, and command line.</p>

<p align="center">
  <a href="https://swap3d.studio/app">Web app</a> ·
  <a href="https://swap3d.studio/developer-api">Developer API</a> ·
  <a href="https://github.com/swap3d/swap3d-js">JavaScript SDK</a> ·
  <a href="https://github.com/swap3d/swap3d-cli">CLI</a>
</p>

Swap3D provides in-browser conversion for individual files and an asynchronous
cloud API for applications, automation, and developer workflows.

## Build With Swap3D

- **Web app:** upload, preview, convert, and download 3D files in the browser.
- **Developer API:** submit asynchronous cloud conversion jobs from your own
  applications and services.
- **CLI:** authenticate, convert files, monitor jobs, and download results
  directly from a terminal or CI environment.
